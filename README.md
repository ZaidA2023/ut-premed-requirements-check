# UT Pre-Med Requirements Check

A single-page tool that checks a UT Austin unofficial transcript (PDF or pasted text) against the
[UT Health Professions Office pre-med course requirements](https://healthprofessions.utexas.edu/health-professions/pre-medical-pathway/pre-med-course-requirements).

- Everything runs in your browser — the transcript is never uploaded anywhere.
- Counts in-progress courses and credit-by-exam (AP/IB) courses, with flags.
- Shows the courses that would finish each unmet requirement.

Open `index.html` in a browser to use it. This is an independent study tool, not an official university
tool — confirm requirements with your advisor and target schools.
